# Example Skill

This is a demonstration skill. When active, follow these guidelines:

## Guidelines
- Be concise and direct in your responses.
- Use bullet points for lists of three or more items.
- When providing code examples, always include brief comments.
- End your responses with a helpful follow-up suggestion when appropriate.
